Architecture Overview - MVC Mapping

This page maps the files and modules in the AstraNotes project to their respective Model-View-Controller (MVC) responsibilities.

Model

The Model represents the data and business logic of the application.

  • models.py - Defines data models and structures
  • db.py - Handles database connections and operations
  • services.py - Contains business logic and service layer functions

View

The View handles the presentation and user interface.

  • templates/base.html - Base template with layout
  • templates/index.html - Main workspace page
  • templates/login.html - User login form
  • templates/register.html - User registration form
  • templates/profile.html - User profile page
  • templates/settings.html - Application settings page
  • static/style.css - Stylesheet for the application

Controller

The Controller manages user input and updates the model and view accordingly.

  • routes.py - Defines API routes and request handlers
  • main.py - Application entry point and server setup

Other Components

  • __init__.py - Package initialization
  • config.py - Application configuration settings
  • tests/test_auth.py - Authentication tests
  • tests/test_health.py - Health check tests
  • docs/ - Documentation files (architecture.md, getting_started.md, etc.)
  • Planning/ - Project planning and requirements documents
  • requirements.txt - Python dependencies
  • pyproject.toml - Project configuration
  • Makefile - Build and development scripts
